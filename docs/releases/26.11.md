# Calcium 26.11 — native Nitrogen dependency libraries

26.11 removes the ten reported import diagnostics by adding native APIs for
subprocess, zipfile, re, urllib.error/request, traceback, importlib.util and
threading, together with urllib/importlib package namespaces.

Regex uses PCRE2, ZIP uses libarchive, downloads/TLS use libcurl, and process/thread
execution uses POSIX APIs. Module presence means the documented API subset is
implemented, not every CPython API. There are no import-only stubs or automatic
CPython fallbacks. Read the [exact contract](../LIBRARIES_26_11.md).

Threads execute actual compiled callbacks with synchronized native object access,
GC roots for suspended threads, separate exception/event-loop contexts, locks,
RLocks and events. Process communication drains output pipes and supports status,
input, redirection and timeouts. HTTP retains certificate verification. ZIP
extraction refuses symlink traversal in archive members.

Native exceptions gain library-specific attributes and source-location traceback
formatting. JSON file streams and simple slotted dataclasses cover further
Nitrogen needs. Regex iterators are lazy. A sanitizer-discovered rooting defect in
regex replacement was fixed before delivery.

Discribe with vendored Nitrogen now compiles and runs --help. A separate probe
imports unmodified Nitrogen and matches Python's publication-name helpers and
InstallResult output. These checks do not establish full application behavior.
Dynamically downloaded Python still needs rebuilding into the executable;
importlib loads compiled registry modules and cannot execute new source files.

Builds require development packages for each selected C library; manifests record
their dependencies and thread flags. CaRT advances to ABI **6**, with a separate
object-cache namespace. Native executables still have no Python runtime or SDK
dependency. No application speedup is claimed by these compatibility changes.

[Recorded Discribe and Nitrogen evidence](../benchmarks/discribe-26.11-compatibility.json)
includes source hashes, native dependency metadata and probe output. Reproduce the
read-only helper check with `examples/native/nitrogen_probe.py` and
`--include-path /path/to/discribe`.

Validation covers 516 passing regression cases with two optional UBSan cases
skipped in the normal run; those two pass separately. All 18 new library tests
pass on Python 3.12, 3.13 and 3.14, including GCC/Clang ASan/UBSan. Wheel/sdist
contents, isolated installed-wheel execution and standalone example archives are
checked. The archive includes `library_tools` and per-program dependency lists.
