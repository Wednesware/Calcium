# Calcium 26.10 — broad native built-in coverage

26.10 adds 23 built-in names and 36 exception/warning types to Bonemarrow, alongside
starred assignment, native identity, larger literals and selected match patterns.
It addresses the built-in and listed syntax failures in the supplied Nitrogen
checkout. It does not claim complete Python built-in or Nitrogen compatibility.

The batch includes any/all; lazy map/filter/reversed and callable-sentinel iter;
base and Unicode conversions; pow/divmod/round; open/input/exit/quit; format,
delattr/vars, id/hash and slice. Exception relationships now include SyntaxError,
ArithmeticError, ConnectionError and warning subclasses.

A complete public-name inventory is exposed through native --info JSON, analysis
metadata and emitted manifests. On the Python 3.14 compiler it reports 129 names
with documented native availability and 23 unsupported names. Dynamic execution,
full reflection, new buffer/value types, async iteration, exception groups and
interactive helpers remain separate runtime projects. Read the
[exact built-in contract](../BUILTINS.md) before inferring compatibility.

Numerical helpers preserve arbitrary-precision modular arithmetic, modular
inverses and ties-to-even rounding. Float rounding uses exact rational operations
instead of rounding an already-imprecise scaled double. Native text hashing uses
process-randomized SipHash. Dictionary/set lookup remains linear.

Native file objects gain path/descriptor opens, exclusive/update modes, input,
line/iterable access and position operations. Shared descriptor read-ahead offsets
are preserved on close. Files retain native resource finalization; no interpreter
or Python I/O implementation is embedded.

Large container literals use checked heap scratch storage; function/call argument
limits remain 128. Match support covers literal, singleton, OR and wildcard cases
with guards. More complex patterns remain explicit diagnostics.

CaRT ABI advances to **5** and uses a separate cache namespace. The compiler's
Python runtime remains a build-time dependency only for native executables.

The user's vendored Nitrogen tree still reports missing standard-library modules:
subprocess, zipfile, urllib, traceback, re, importlib and threading. Full Discribe
compilation/execution with that dependency tree remains blocked. These errors are
retained rather than hidden by stubs or automatic CPython fallback.

Validation covers native O0/O3 parity, numerical boundaries, large literals,
identity/hash behavior, descriptor ownership and lazy iterators, including
GCC/Clang ASan/UBSan checks. The Python 3.14 regression suite passes 498 tests
with two optional UBSan tests skipped; those two pass when enabled separately.
All 17 new tests also pass on Python 3.12 and 3.13. Wheel/sdist contents, an
isolated installed-wheel smoke test and standalone examples pass. No general
application speedup is asserted.

Checked-in evidence: [built-in inventory](../benchmarks/builtins-26.10.json),
[Nitrogen blockers](../benchmarks/nitrogen-26.10-blockers.json), and
[Discribe core parity](../benchmarks/discribe-core-26.10.json).

The standalone example archive includes `builtin_tools`, which compares the new
iterator, numeric, starred-assignment and match behavior against Python before
packaging the executable.
