# Calcium 26.5

Calcium 26.5 adds a static optimization and fallback report, making it easier to
see which parts of an ordinary Python application receive native lowering and
which language features block broader coverage.

## Optimization and fallback report

```sh
ca build path/to/package -O3 --optimization-report
ca check path/to/package -O3 --optimization-report
ca check path/to/package -O3 --optimization-report --format json
```

The report includes:

- Counts of native/fallback source functions and module modes.
- Qualified names, source locations and module source hashes.
- Located fallback reasons, distinguishing closures, nested functions, decorators,
  annotations, classes, async, generators, future flags, dynamic features and other
  unsupported syntax.
- Enclosing module/class/function boundaries that force otherwise eligible
  functions into fallback.
- Primary blocker counts that sum to the fallback-function total, plus explicitly
  overlapping counts for additional known blockers.
- Existing optimizer decisions, including operation counts and scalar-kernel
  assumptions where available.

Named functions, async functions, methods, nested functions and lambdas are counted
once per source definition. Classes are counted separately. Whole-module fallback
correctly classifies every function in that module as fallback; class and enclosing
function boundaries are also respected. Removing one blocker does not guarantee
that affected functions will become native.

Text reports go to stderr. JSON output and the Python API expose
`optimization_report` / `result.optimization_report`; generated C manifests include
the same report. Detailed boundary reasons are stored once per module and referenced
by ID. Strict-mode rejection still returns coverage when analysis completes, and
partial reports explicitly identify incomplete analysis. Existing
`--report-fallbacks` and `--report-optimizations` remain available.

## Discribe findings

The analyzed local Discribe snapshot contains **38 source function definitions:
2 selected for native lowering and 36 in fallback**, across six modules and six
classes. Primary blockers are:

| Primary blocker | Functions |
| --- | ---: |
| Future compiler flags | 13 |
| Classes | 10 |
| Annotations | 7 |
| Closures | 6 |

`discribe.core` has a whole-module boundary caused by
`from __future__ import annotations`. The report also exposes additional known
blockers underneath that boundary. Discribe built successfully without being
launched. The source fingerprint, counting rules and overlapping categories are
recorded in the [report reference](https://github.com/Wednesware/Calcium/blob/26.5/docs/OPTIMIZATION_REPORT.md).

## Scope and compatibility

This is a diagnostic release. Native language support and runtime optimization
semantics are unchanged from 26.4. The report describes static source coverage,
not execution time, runtime hotness or dynamic fallback percentages. Analysis does
not import or execute the application. External packages and unresolved dynamic
imports are outside the reported project coverage.

`--profile-startup`, broader native language support, cross-module scalar calls,
additional type specialization, lookup caching and LTO remain separate work. No
new performance speedup is claimed. Native builds continue to support Linux with
GIL-enabled CPython 3.12–3.14, GCC or Clang, matching development headers and shared
libpython. Existing native-frame/reflection and platform limitations remain.

## Validation and downloads

The reporting implementation passed **308 tests per version on CPython 3.12, 3.13
and 3.14**, with two opt-in UBSan tests run separately using GCC and Clang. Tests
cover enclosing boundaries, overlapping reasons, source locations, strict rejection,
partial analysis, namespace packages, manifests, clean CLI JSON and nonexecution
of input programs. Formatting, wheel/sdist builds and isolated installed-wheel
smoke checks pass across the matrix.

Release assets include the Python wheel, source distribution, Nitrogen-compatible
`calcium.zip` and `SHA256SUMS`. Package metadata, CLI version and Nitrogen metadata
are aligned at **26.5**. Both `ca` and `calcium` console commands remain available.
